# cpp-multithreaded-tcp-server

Надежный многопоточный TCP-сервер на C++17 для платформы Windows. Сервер принимает текстовые команды от клиентов и параллельно обрабатывает их с помощью собственного пула потоков. Проект демонстрирует уверенное владение сетевым программированием (Winsock2), примитивами синхронизации и паттерном проектирования Producer-Consumer.

Код написан с упором на чистую архитектуру: использование RAII для управления ресурсами ОС, отсутствие утечек памяти, безопасная работа с потоками.

### Возможности

* **Thread Pool (Пул потоков):** Сервер инициализируется с пулом из 4 рабочих потоков. Главный поток занимается только принятием соединений (`accept`), не блокируясь на чтении данных.
* **Safe Queue:** Потокобезопасная очередь задач, защищенная `std::mutex` и `std::condition_variable`.
* **RAII управление сокетами:** Инициализация и очистка библиотеки Winsock2 (WSAStartup/WSACleanup) инкапсулирована в класс `WsaSession`.
* **Текстовый протокол:** Взаимодействие происходит построчно, сервер автоматически очищает входящие команды от символов переноса каретки `\r\n`.
* **Диагностика соединений:** Корректная обработка разрывов связи (graceful disconnect) и логирование кодов ошибок через `WSAGetLastError()`.

### Поддерживаемые команды

Сервер поддерживает следующие текстовые команды:

| Команда | Описание | Пример ответа |
| :--- | :--- | :--- |
| **PING** | Проверка активности соединения | `PONG` |
| **ECHO \<text>** | Возвращает переданный текст обратно | `<text>` |
| **TIME** | Запрашивает текущее время на сервере | `2026-07-25 15:30:45` |
| **QUIT** | Закрывает соединение со стороны сервера | `BYE` |
| *Любая другая* | Обработка неизвестной команды | `UNKNOWN COMMAND` |

Проект использует систему сборки CMake.
* **Требования:** CMake ≥ 3.15, компилятор с поддержкой C++17. 
* **ОС:** Windows (проект линкуется с системной библиотекой `ws2_32`).

# Генерация файлов сборки
