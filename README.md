# cpp-multithreaded-tcp-server

Надежный многопоточный TCP-сервер на C++17 для платформы Windows[cite: 2, 7]. Сервер принимает текстовые команды от клиентов и параллельно обрабатывает их с помощью собственного пула потоков[cite: 6, 8]. Проект демонстрирует уверенное владение сетевым программированием (Winsock2)[cite: 9], примитивами синхронизации и паттерном проектирования Producer-Consumer[cite: 5, 8].

Код написан с упором на чистую архитектуру: использование RAII для управления ресурсами ОС[cite: 8, 9], отсутствие утечек памяти, безопасная работа с потоками[cite: 5, 8].

### Возможности

* **Thread Pool (Пул потоков):** Сервер инициализируется с пулом из 4 рабочих потоков[cite: 6, 8]. Главный поток занимается только принятием соединений (`accept`), не блокируясь на чтении данных[cite: 6, 8].
* **Safe Queue:** Потокобезопасная очередь задач, защищенная `std::mutex` и `std::condition_variable`[cite: 5].
* **RAII управление сокетами:** Инициализация и очистка библиотеки Winsock2 (WSAStartup/WSACleanup) инкапсулирована в класс `WsaSession`[cite: 9].
* **Текстовый протокол:** Взаимодействие происходит построчно, сервер автоматически очищает входящие команды от символов переноса каретки `\r\n`[cite: 6].
* **Диагностика соединений:** Корректная обработка разрывов связи (graceful disconnect) и логирование кодов ошибок через `WSAGetLastError()`[cite: 6].

### Поддерживаемые команды

Сервер поддерживает следующие текстовые команды[cite: 6]:

| Команда | Описание | Пример ответа |
| :--- | :--- | :--- |
| **PING** | Проверка активности соединения | `PONG` |
| **ECHO \<text>** | Возвращает переданный текст обратно | `<text>` |
| **TIME** | Запрашивает текущее время на сервере | `2026-07-25 15:30:45` |
| **QUIT** | Закрывает соединение со стороны сервера | `BYE` |
| *Любая другая* | Обработка неизвестной команды | `UNKNOWN COMMAND` |

* **Требования:** CMake ≥ 3.15, компилятор с поддержкой C++17[cite: 2]. 
* **ОС:** Windows (проект линкуется с системной библиотекой `ws2_32`[cite: 2]).
